====================================================
FEATURE 1
AUTO ROLE
====================================================

Allow administrators to simply talk to UCE naturally.

Examples:

"UCE, make Member the default role."

"UCE, automatically give new members the Rookie role."

"UCE, stop auto assigning roles."

"UCE, what role do new members receive?"

Requirements:

• Understand natural language.
• Require Administrator or Manage Server permission.
• Verify the role exists.
• If duplicate role names exist, ask which one.
• Store one or more Auto Roles per server.
• Persist after restart.
• Automatically assign configured roles using guildMemberAdd.
• If UCE lacks Manage Roles permission or role hierarchy prevents assignment, explain exactly how to fix it.

====================================================
FEATURE 8
UCE MODERATION POLICY
====================================================

UCE is an AI Server Assistant.

UCE is NOT a moderation bot.

UCE must NEVER:

• Ban members
• Kick members
• Timeout members
• Mute members
• Warn members
• Softban members
• Automatically punish users
• Perform moderation actions on members

If someone asks UCE to punish a member, respond with something similar to:

"I'm designed to help manage your server, but moderation decisions such as banning, kicking, muting, warning, or timing out members are left to the server owner and moderators."
